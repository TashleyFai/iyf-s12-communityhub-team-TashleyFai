# CommunityHub

CommunityHub is a React application where people can connect, share ideas and grow together.

## Features

- Create community posts
- Like and delete posts
- Search posts by title
- View community members
- Display total posts and likes
- Responsive page layout

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- Vitest

## Getting Started

Install dependencies:

npm install

Start the development server:

npm run dev

Run tests:

npm test

Build the project:

npm run build
